# Security

`install.ps1` only copies the wallpaper files into Wallpaper Engine's `projects\myprojects` folder and tells Wallpaper Engine to open it. It needs no admin rights, and it downloads only from this repository over HTTPS.

The wallpaper itself is a static page with no network requests, cookies, or tracking.

To report a problem, open a private advisory under this repo's Security tab or reach me through https://diegoarivada.dev.
